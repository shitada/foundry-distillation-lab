# 公開サンプルと実験データの区別

`traces.jsonl` は、移植した日本語の架空注文・配送ツールを呼び出し、
`scripts\generate_samples.py` で作った **説明用のスクリプト生成例** です。
モデル・Foundry・teacherを呼んだ結果ではありません。
配送照会のみ20会話を含み、全業務の学習・性能評価に十分なデータではありません。

用途は、JSONL検証、会話単位分割、評価①の問題作成のオフライン動作確認です。
返品・交換・返金等の能力、SFTの改善、本番品質を実証しません。
生成元の日本語商品・語彙・業務処理とライセンスは
`docs\reference\provenance.json` と `THIRD_PARTY_NOTICES.md` を参照してください。

新しいteacher収集データは `runs` に保存し、内容・権利・個人情報を確認してから学習に採用します。
最終評価を見て改善した場合、その同じ最終評価を独立した最終判定に使い続けません。
